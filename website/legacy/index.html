DeepDriveCleaner

Version 0.3.0 · Menu bar app + CLI

A disk cleanup utility for developers. Finds virtual environments, node_modules, build outputs, tool caches, Xcode data, local models and VM images.

The menu bar app and the ddc command use the same engine. Scan to see what's there, review the findings, then confirm what to clean.

Scan: read-onlyClean: review + confirm

Install with Homebrew

brew install --cask smartandpoint/tap/deepdrivecleaner

Requires macOS 26 and Apple Silicon. Installs the app and the ddc command. Signed and notarized.

Open the app from Applications and grant Full Disk Access when prompted.

Release 0.3.0 ↗Older macOS / CLI only ↗

Windows: No release is available for this platform yet.

Command-line quick start

Full CLI reference ↗

Commands below describe the current macOS release.

  1. Scan

    Read-only. Lists findings by risk and type.

    ddc scan

  2. Preview the plan

    Shows what would happen without changing files.

    ddc clean --dry-run

  3. Review and clean

    Interactive: inspect the plan, change selections and confirm.

    Cleaning deletes files. Review the plan and confirm your selection. Disclaimer ↗

    ddc clean
More commands and machine-readable output
ddc scan ~/Projects
Scan a specific folder.
ddc scan --json
Read-only report for scripts and agents. Schema ↗
ddc rules --json
Detection rules and their risk classes. Schema ↗

Using this with an agent

Start with a read-only scan or JSON report. Discuss the findings with the person using the Mac; a report is not consent to delete files. Do not skip the review and confirmation step.
