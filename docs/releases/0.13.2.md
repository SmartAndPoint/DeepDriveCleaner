Cleaning Hugging Face downloads no longer signs you out, another user's files are never cleaned, and names that are not UTF-8 no longer break a report.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.13.2/DISCLAIMER.md).

- **Hugging Face keeps its token.** The ML models rule used to take all of `~/.cache/huggingface`, the sign-in token with it. It now finds `hub`, `xet` and `datasets`, the downloads, and leaves `token` and `stored_tokens` where they are.
- **Another user's files stay.** A finding that holds files or folders of another user, as a container running as root leaves in a project, is listed as "another user's", never selected, and skipped before anything is moved if a plan names it. Linux reports the owners; macOS does not yet, so nothing changes on a Mac.
- **Names that are not UTF-8.** Linux allows them; a report used to fail on one. Such a path is now written with � for the bytes that are not text, and the scan and clean reports count them in `lossy_paths`. macOS never has such names.
- **Linux, underneath.** Directory reading, verified removal, volumes, process checks and the freedesktop Trash are ported to Linux. Linux is not supported yet: `ddc` still refuses to scan or clean there.

**Upgrading.** The app offers this version itself: Update and Relaunch, or Settings → General → **Check Now**. `brew upgrade --cask deepdrivecleaner` and the zip below work too. Report formats changed since 0.12.1: scan schema 4 and progress schema 4 (the reason `foreign-owner`), clean schema 6 and journal schema 6 (the skip reason `foreign-owner`), and the optional `lossy_paths`. Update the app and the CLI together; a report from another version is named as such and not read. Scripts that read the reports need the new versions.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
