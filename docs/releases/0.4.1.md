Fixes from a user's screen recording of the clean flow: Docker Desktop, items that would be skipped anyway, and what stays selected after a clean.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.4.1/DISCLAIMER.md).

- **Docker prune runs only while Docker Desktop answers.** Before it prunes, DeepDriveCleaner asks Docker Desktop for its engine version, and waits up to 5 seconds. If Docker Desktop is not running, does not answer, or has no `desktop-linux` context, the Docker item is skipped and says why. No prune command runs. The confirmation sheet predicts this before you clean. When a prune does fail, the result shows Docker's own last line, not just an exit code.
- **Clean is not offered when every item would be skipped.** When the sheet's check finds that every item would be skipped, the Clean button is off. The sheet then says what to do: quit the named apps, wait for a process, start Docker Desktop, or Scan Again for items that changed since the scan. "Frees about" leaves out the items that would be skipped. Clean also waits for the check to finish, and the check has a **Stop** button.
- **After a clean, only skips that can clear stay selected.** An item stays selected only when one step of yours can clear its skip: an app was running, a process held the folder, or Docker Desktop was not answering. Items that changed since the scan, tool commands that already ran, and causes that never clear are deselected. The result says how many items stay selected. When some items changed, it offers **Scan Again**. A tool-cleaned row keeps a short note until the next scan, such as "Pruned 3 min ago".
- **Fixes.**
  - An item that changed after the scan was skipped at every later clean, until a full scan. The report saved after a clean now holds what the clean's own check found.
  - The confirmation sheet no longer shows an empty panel while it closes.
- **For scripts.** `ddc clean --json` reports version 3: a skip reason `tool-not-ready` with `program` and `detail`, and each tool command's `output`. `--progress json` events are version 2, and `actions.jsonl` lines are version 3. See [`docs/clean.schema.json`](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.4.1/docs/clean.schema.json) and [`docs/progress.schema.json`](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.4.1/docs/progress.schema.json).

**Upgrading.** Run `brew upgrade --cask deepdrivecleaner`. The upgrade quits the app. It opens again at your next login if Open at login is on, or when you open it yourself. Do not upgrade while the app is cleaning.
