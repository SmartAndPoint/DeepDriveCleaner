- **Per-session footprint.** With sizes, `ddc disk agents` measures Claude Code's temporary folder (`/private/tmp/claude-<uid>` on macOS, under `CLAUDE_CODE_TMPDIR` when that is set), which can hold more than everything Claude Code keeps in the home folder. Each session gets a row: its transcript and companions, its checkpoints in `~/.claude/file-history`, its temporary folder (scratchpad, tasks, images) and the total, with whether it is live, not live or unknown, decided as the cleanup's session check decides it. A session whose transcript is gone still gets a row for its temporary folder. The text shows the ten largest sessions and the rest in one line; `--json` lists them all. A live session's files are only described; a row that is not live says what its temporary folder holds, and `--json` gives its path. The command still reads names, sizes and the session records' named fields, never a transcript's content, and removes nothing. `--no-sizes` measures none of it.
- **Agent skill v0.** `agents/claude-code/ddc/SKILL.md` and `agents/AGENTS.snippet.md` teach coding agents to ask `ddc` before guessing about the disk: read-only questions in JSON, and the cleanup handed to the person. Structure tests check that every field they cite exists, every `ddc` line parses, and no runnable block removes anything. `agents/README.md` says how to install them.

- **A demo home.** `bench/demo/agent-ghosts.sh` builds a synthetic home full of coding-agent data, one session live, for demos that never touch real files.

**Upgrading.** `brew upgrade --cask deepdrivecleaner`, the app's Check Now, or the zip below. The agents report stays schema 1: `footprints` and `temp_root` under Claude Code's `sessions` are new and optional, and the harness bytes are still the home folder's alone. The app does not show the footprint yet.
