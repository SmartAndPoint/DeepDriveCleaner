A file or folder name that is not valid UTF-8 no longer breaks a JSON report.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.13.1/DISCLAIMER.md).

- **Names that are not UTF-8.** Linux allows them; a report used to fail on one. Such a path is now written with � for the bytes that are not text, and the scan and clean reports count them in `lossy_paths`. macOS never has such names, so nothing changes on a Mac.

**Upgrading.** The app offers this version itself: Update and Relaunch, or Settings → General → **Check Now**. `brew upgrade --cask deepdrivecleaner` and the zip below work too. Report formats are unchanged from 0.13.0 but for the optional `lossy_paths`.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
