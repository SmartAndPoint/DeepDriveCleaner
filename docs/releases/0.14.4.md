`ddc scan` of a folder now suggests the `ddc clean` that reviews that folder, not your whole home.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.14.4/DISCLAIMER.md).

- **The suggested clean keeps your paths.** After `ddc scan ~/Projects` the summary said "run `ddc clean`", and `ddc clean` with no path reviews the home or the folders `settings.json` names. It now says "run `ddc clean ~/Projects`": the scanned paths, each one shell word (`~/` under the home, single quotes around a name with spaces or quotes), ready to paste. A scan of the default folders still suggests plain `ddc clean`.
- **Linux load runs.** The nightly load run on Linux no longer measures `ddc disk`, which Linux does not offer yet: its `system-root` profile failed on the exit code 69 that says so. The profile still checks its tree and measures the scan and the dry-run clean.
- **Linux on ARM builds clean.** On aarch64 a file's link count is 32 bits, not 64 as on x86_64, and clippy refused the conversion that x86_64 needs. Nothing changed at run time; the whole Linux test suite passes on an aarch64 machine, with the same skips as on x86_64.
- **The native Linux run keeps to its folder.** `scripts/native-linux.sh --setup` installs rustup, the pinned toolchain and nextest inside `~/ddc-native` for the host's architecture, as the Windows script does, and runs never use the host's own `~/.rustup` or `~/.cargo`. Builds skip incremental data, as CI does, and the script says when its target folder passes 40 GiB instead of removing anything.

**Upgrading.** `brew upgrade --cask deepdrivecleaner`, the app's Check Now, or the zip below. No report schema changed. 0.14.2 and 0.14.3 were not released on their own; this release carries them.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
