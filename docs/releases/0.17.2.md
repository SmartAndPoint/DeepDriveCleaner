The Windows port goes on, two steps of fifteen (story "Windows scanner and rule catalog"). Nothing changes on macOS or Linux. 0.17.1 was not released on its own; this release carries it.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.17.2/DISCLAIMER.md).

- **One call for a file's identity, links and size.** Every part of ddc reads a file's identity, hard-link count and allocated size through one call per platform, which Windows can answer too. On macOS and Linux the numbers are the same `stat` fields as before (0.17.1).
- **Windows reads them from the file's own handle.** The identity is the volume and the file id; the links and the size come from the same open file, also past the 260-character path limit. A file system whose ids do not fit, or that gives none, is refused rather than guessed, so nothing on it can be planned by mistake.
- Windows is still unsupported: `ddc` there runs only `--version`, `--help` and `rules`.

**Upgrading.** `brew upgrade --cask deepdrivecleaner`, the app's Check Now, or the zip below. Nothing you can see changed on macOS or Linux.
