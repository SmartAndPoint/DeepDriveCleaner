First public release of DeepDriveCleaner: a terminal tool that finds what development leaves on a Mac's disk and cleans it only after you confirm.

- `ddc scan`: Python virtual environments, `node_modules`, build outputs, package and toolchain caches, Xcode data, ML models and VM images, grouped by risk class (`safe`, `rebuildable`, `review`, `user-data`), with a versioned JSON report.
- `ddc clean`: a fresh scan, a plan you review item by item, a re-check of every item right before it is touched, deletion through a tombstone or the Trash, and a journal of every action.
- `ddc schedule install`: a daily background scan that notifies when a lot can be freed and never deletes anything.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
