Benchmarks run on the owner's Linux machines as the tests do.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.14.8/DISCLAIMER.md).

- **`native-linux.sh --make <target>`.** It runs a make target (`load`, `load-baseline`, `scaling`) in the same container as the Linux tests, on a Linux machine or in WSL. It then copies the measurements back to the local `target/native-linux/load`, so they stay out of the repository. `DDC_LINUX_LIMITS=<file>` judges a load run against limits that machine recorded, instead of the hosted runner's `bench/load-limits-linux.tsv`.

**Upgrading.** Nothing in the app or the CLI changed. `brew upgrade --cask deepdrivecleaner`, the app's Check Now, or the zip below.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
