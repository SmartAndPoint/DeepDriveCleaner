The nightly run now judges the Linux build's memory and CPU against limits of its own.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.14.5/DISCLAIMER.md).

- **Linux load limits.** `bench/load-limits-linux.tsv` holds the memory and CPU limits of every load profile on Linux, recorded by the nightly `load-linux` job on a GitHub-hosted Ubuntu 24.04 runner. That job now runs every profile at size M, three runs each, and fails when a command goes over them, as the macOS jobs do with `bench/load-limits.tsv`.

**Upgrading.** Nothing in the app or the CLI changed. `brew upgrade --cask deepdrivecleaner`, the app's Check Now, or the zip below.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
