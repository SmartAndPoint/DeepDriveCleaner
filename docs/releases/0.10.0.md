Sort a group's rows by name, size or last change, and take a folder's protection away from the command line.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.10.0/DISCLAIMER.md).

- **Sort in the Review window.** Each group has a header with **Name**, **Size** and **Changed**. Click a title to sort by it, click again to reverse. Changed shows the newest change inside each folder, so the Python environments or `node_modules` you have not touched for a year come first. Rows with no date go last either way. The Items view has the same header in place of its old menu, and the sort is kept across launches. Sorting never changes what is selected.
- **`ddc keep remove <folder>`.** Removes the `.ddc-keep` file of one folder the last scan named as kept, and nothing else: it refuses a folder outside the scanned roots or one that changed since the scan, and writes what it did to the journal. At a terminal it asks first.
- **The scan report says what protects a kept finding and when each finding last changed.** `protection` names the `.ddc-keep` file, exclusion or skip behind a kept finding; `modified` is the newest change inside a finding. Both are optional; the report stays at schema version 2.
- **`ddc rules --platform linux|windows`** prints another platform's rules, and the human output lists each rule's folders.

**Upgrading.** From 0.8.0 the app offers this version itself: the popover says "Version 0.10.0 is available", and **Update and Relaunch** installs it. Settings → General → **Check Now** checks at once. `brew upgrade --cask deepdrivecleaner` and the zip below work too. Scripts that read the journal (`journal.jsonl`) see schema version 4 and a new `keep-remove` line.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
