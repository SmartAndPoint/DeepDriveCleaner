Pick a coding agent's sessions one by one in the Review window, and see which version you run and what the last update check found.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.12.1/DISCLAIMER.md).

- **Sessions one by one.** In the Coding agents group, Claude Code's transcripts and file history are no longer one row: each session folder opens to its sessions, and you tick the ones to remove. A session in use stays locked and says why. Sessions are never part of Select all, and they only go to the Trash, never deleted for good. The confirmation says that `--resume` and `/rewind` stop working for a session until you put it back from the Trash.
- **Current version in Settings.** Settings → General shows the version you run and what the last check found: Up to date, the version available, Checking…, Not checked yet, or The last check failed. A Check Now that finds nothing now says so.

**Upgrading.** The app offers this version itself: Update and Relaunch, or Settings → General → **Check Now**. `brew upgrade --cask deepdrivecleaner` and the zip below work too. Report formats are unchanged from 0.11.1. 0.12.0 was tagged but never published: this is its content.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
