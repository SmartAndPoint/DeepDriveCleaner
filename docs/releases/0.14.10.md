Delete all permanently in one click, and no error after an update.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.14.10/DISCLAIMER.md).

- **Delete all permanently.** The confirmation sheet showed a Delete permanently checkbox on each Review item the Trash would take, and a tester had to tick it 14 times. Once two such items are in the sheet, one checkbox above the list now ticks them all, or unticks them all when all are ticked; it shows mixed when some are. Each item still carries its own choice, so the clean gets the same list as ticking each one by hand, and the Settings switch "Delete Review items instead of moving them to the Trash" is unchanged. Since one click can change every item from a Trash move to a delete, the warnings check runs again.
- **No error after an update.** After an update the Whole Disk view said "The Whole-Disk Report Could Not Be Read (schema 1)" with a warning triangle, because the last report was written by the older version. It now says "Scan Whole Disk Again". A home scan report from an older version is treated as no report: the popover offers the first scan, and the menu bar icon shows no warning. A report from a newer version still cannot be read, and says to update DeepDriveCleaner.

**Upgrading.** `brew upgrade --cask deepdrivecleaner`, the app's Check Now, or the zip below. No report schema changed; the CLI is unchanged.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
