A folder that holds another user's files is listed and never cleaned, and the groundwork for Linux.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.13.0/DISCLAIMER.md).

- **Another user's files stay.** A finding that holds files or folders of another user, as a container running as root leaves in a project, is listed as "another user's", never selected, and skipped before anything is moved if a plan names it. Linux reports the owners; macOS does not yet, so nothing changes on a Mac.
- **Linux, underneath.** Directory reading, verified removal, volumes, process checks and the freedesktop Trash are ported to Linux. Linux is not supported yet: `ddc` still refuses to scan or clean there.

**Upgrading.** The app offers this version itself: Update and Relaunch, or Settings → General → **Check Now**. `brew upgrade --cask deepdrivecleaner` and the zip below work too. Report formats changed: scan schema 4 and progress schema 4 (the reason `foreign-owner`), clean schema 6 and journal schema 6 (the skip reason `foreign-owner`). Update the app and the CLI together; a report from another version is named as such and not read. Scripts that read the reports need the new versions.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
