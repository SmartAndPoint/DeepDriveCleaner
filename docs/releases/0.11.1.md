Coding agents' data in the Review window, cleaned only when no session uses it, and Remove Protection on a kept folder.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.11.1/DISCLAIMER.md).

- **Coding agents in Review.** A new group holds what Claude Code, Codex, opencode and Cursor keep in the home folder. Debug logs and to-dos are Safe and deleted. History, file history, transcripts, Codex sessions and runtimes, opencode's data and Cursor's agent data are Review and go to the Trash. Memory, live session records, shell snapshots, plugins, worktrees and opencode's credentials and index are never touched. History never goes in with `--yes`.
- **A session in use stays.** Claude Code's transcripts and file history are listed one session at a time. A session that is running, changed in the last 10 minutes, or held open by a process is locked; when ddc cannot tell, it says why and keeps it. The check runs at the plan and again before each move. A session goes to the Trash with its companion files, the transcript last, so Put Back restores it whole. A whole Codex, opencode or Cursor folder is skipped while that tool runs.
- **Review… from the Whole disk view.** The Coding Agents section says how much of it is in Review and opens the Review window on the group.
- **Remove Protection…** on a row in "Protected by you". Each row now says what protects it: a `.ddc-keep` file, an exclusion or a skip, and what the folder would be otherwise. Remove Protection removes the `.ddc-keep` (through `ddc keep remove`) or the Settings entry, warns when git tracks the marker, and scans again: the folder then appears in its own group, where it can be cleaned.

**Upgrading.** The app offers this version itself: Update and Relaunch, or Settings → General → **Check Now**. `brew upgrade --cask deepdrivecleaner` and the zip below work too. Report formats changed: scan schema 3, clean schema 5, progress schema 3, journal schema 5 (an optional `entry` on the lines of a session's companion files). Update the app and the CLI together; a report from another version is named as such and not read. Scripts that read the reports need the new versions.

How it was built, decision by decision, is public too: [DeepDriveCleaner-projectstore](https://github.com/SmartAndPoint/DeepDriveCleaner-projectstore).
