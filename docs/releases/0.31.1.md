A Windows step on the way to Windows support: the Stop of the coming Windows app. Windows is still not supported, so nothing of this runs outside the tests yet. On macOS and Linux nothing changes.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.31.1/DISCLAIMER.md).

- **Windows: the app's Stop.** Windows has no SIGTERM, so the coming Windows app will stop a run through a named event it creates and passes to ddc (a hidden `--cancel-event` option). When the event is set during a clean, ddc finishes the current item, ends the tool that runs, writes its journal and report and exits with 143, as SIGTERM does on macOS. A scan, or a clean that has not reached its first item yet, ends at once with 143, and nothing was changed.
- **A wrong event name is refused.** If ddc cannot open the event, or the option is given on macOS or Linux, it exits with 2 before doing anything.
- **A test fix.** A property test made folders with random short names, and one could be `nul`, `con`, `aux` or `prn`, which Windows treats as a device. Those names are no longer made.

**Report schemas.** None change.

**Upgrading.** `brew upgrade --cask deepdrivecleaner`, the app's Check Now, the install script, or the zip below.
