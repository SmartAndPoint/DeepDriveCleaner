`ddc disk agents` now reads Claude Code's temporary folder only when it is your own, and the agent skill describes the per-session footprint that 0.14.0 shipped.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.14.1/DISCLAIMER.md).

- **The temporary folder must be yours.** In a shared `/tmp` anyone could make `claude-<uid>` first. `ddc disk agents` now opens it only when it is a folder the current user owns, not a symbolic link. Otherwise `temp_root` says why in `refused` (`symlink`, `not-a-folder` or `not-owned`), has no `bytes`, and no session counts temporary bytes from it. The text says "not read" and why.
- **The skill knows the footprint.** `agents/claude-code/ddc/SKILL.md` and `agents/AGENTS.snippet.md` no longer say "when available". They say that `sessions.footprints[]` and `sessions.temp_root` are Claude Code's only and need sizes, so an agent that wants each session's bytes leaves `--no-sizes` out. They also name a row's `state` (`live`, `not-live`, or `unknown`, which counts as live), `live_by`, `unknown_cause` and its byte fields. When `unreadable` is above 0, `temp_root.bytes` is a lower bound; it is absent when the folder is skipped or refused. The structure tests check every one of these names against the schema.
- **Tests.** One proves `--no-sizes` never lists the temporary folder: the directory entries read are the same with 400 files in it as with none. The CLI's end-to-end test now has an ended session whose transcript is an hour old and a `bash-edit-diff` folder, and checks that the session is not live and the remainder is that folder's bytes. The app's agents fixtures are checked against the schema and read back unchanged.
- **The demo home refuses first.** `bench/demo/agent-ghosts.sh` refuses a folder inside the real home before it makes anything. It used to leave an empty folder behind. It checks the path as given and its nearest existing parent with links resolved, and refuses a path with `..`.
- **README.** A note that the project was a DEV Hacktoberfest challenge entry at v0.14.0.

**Upgrading.** `brew upgrade --cask deepdrivecleaner`, the app's Check Now, or the zip below. The agents report stays schema 1: `refused` under `temp_root` is new and optional.
