A Claude Code worktree reached through a path in another case is now still Claude Code's, and a category in `ddc scan` counts what lies inside its worktrees. 0.26.1 was not released on its own; this release carries it.

> **DeepDriveCleaner deletes files.** It can remove almost anything it is told to, by you or by an agent acting for you. Use it at your own risk: nobody who made it is responsible for what it removes. Read [DISCLAIMER.md](https://github.com/SmartAndPoint/DeepDriveCleaner/blob/v0.26.2/DISCLAIMER.md).

- **A worktree's harness, whatever the case of the path.** On a case-insensitive volume, the default on macOS, a scan root spelled in another case (`~/projects` for `~/Projects`) made a Claude Code worktree under `.claude/worktrees` look like your own. It was kept, never selected, so nothing was at risk, but it was named wrong. ddc now also tells that folder by its identity, not only by its spelling.
- **`ddc scan`: the category header counts what lies inside worktrees.** Since 0.26.0 the findings inside a worktree are listed under it. The category's header line now also says how many lie inside them and their size ("project-artifact · 10 items · 10.0 MiB, and 20 inside them, 20.0 MiB"), so a big `.venv` inside a small worktree is not hidden. Other headers are unchanged.
- **Tests for worktrees.** The clean runs no `core.fsmonitor` helper; a person's own worktree forced into a `--yes` plan, one a process works in, and a git that hangs or prints garbage at the clean are all kept; a hand-made copy listed by path is refused before any git command; the selected worktree's hint names its branch; a report that ddc 0.25.0 wrote of a worktree still reads, in the CLI and in the app.
- **Windows (0.26.1).** `ddc keep remove` deletes a read-only `.ddc-keep`, and a failed folder delete clears read-only marks on FAT and exFAT before its retry. Windows is still not supported, so nothing of this runs outside the tests yet; on macOS and Linux nothing changes.

**Report schemas.** None change: scan 6, clean 10, journal 10, progress 8.

**Upgrading.** `brew upgrade --cask deepdrivecleaner`, the app's Check Now, the install script, or the zip below.
